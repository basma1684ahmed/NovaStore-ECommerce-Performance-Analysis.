# 📊 NovaStore E-Commerce Performance Analysis (2025)
An end-to-end data analytics project evaluating 30,000 sales transactions for NovaStore in 2025. This project covers the full analytics workflow: data auditing, cleaning, DAX modeling, interactive dashboard design in Power BI, and executive business recommendations.
## 📌 Executive Summary (KPIs)
* **Total Revenue:** $6.53M
* **Total Profit:** $1.17M
* **Profit Margin:** 17.88%
* **Total Orders:** 30,000
## 🔍 Key Business Insights
* **Operational Inefficiencies:** Only **66.2%** of orders are completed successfully. Returns (**17.1%**) resulted in a direct net loss of **-$116.4K**, while cancellations accounted for **16.7%**, meaning over one-third of operational effort brings zero revenue.
* **Discount Leakage:** Identified **366 completed orders with negative profits** due to excessive discounting (averaging 23.4%), particularly in the Electronics category (e.g., Laptop Pro 14, Smartphone X).
* **Geographical Dominance:** Cairo and Alexandria drive over **46%** of total revenue ($1.82M and $1.20M respectively), whereas Canal Cities and Upper Egypt show untapped expansion potential.
## 🛠️ Tools & Technologies Used
* **Microsoft Excel:** Data quality assessment, duplicate removal, text handling, and pivot table analysis.
* **Power Query:** ETL, type validation, and missing value imputation (`Unknown`).
* **Power BI & DAX:** Data modeling, custom measures creation (`Total Sales`, `Total Profit`, `Profit Margin`, `Return Rate`), and interactive dashboard design.
## 🎯 Strategic Recommendations
1. **Discount Capping:** Implement a strict 15% discount threshold on high-value electronics to safeguard profitability.
2. **Mitigate Returns:** Audit product specifications for frequently returned items and revisit return shipping policies to reduce the $116K loss.
3. **Regional Strategy:** Optimize logistics and delivery times in Canal Cities and Upper Egypt to boost fulfillment and sales conversion.
